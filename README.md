# EchoMemory UI Demo

This is a standalone, UI-only preview of EchoMemory prepared for static hosting on Vercel.

It intentionally does not include the Python backend, local AI models, databases, or credentials. The demo interactions run in the browser and save preview memories to localStorage.

## Deploy on Vercel

1. Create a separate GitHub repository for this folder.
2. Push the files in this folder to that repository.
3. Import the repository into Vercel.
4. Choose `Other` as the framework preset.
5. Leave the build command, install command, and output directory empty.
6. Deploy.

The original EchoMemory repository is not changed by this UI demo.
